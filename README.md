# python-university-projects


Данный репозиторий содержит комплект лабораторных и практических работ, выполненных мной в рамках обучения в университетском курсе программирования на Python.

Проект оформлен в виде единого пакета с удобным интерактивным консольным меню для запуска любой работы.


## Темы работ и структура проекта

* `runProject.py` — главный исполняемый файл для запуска интерактивного меню.
* `packageForPracticeTasks/` — основной пакет с работами и учебными материалами по темам:
  * **Работа со списками** (базовые операции, срез, методы `list`)
  * **Сложная обработка списков** (итерации, преобразования и алгоритмы)
  * **Запись списков во внешние программы и работа с Pandas**
  * **Комплексная обработка табличных данных** (файлы Excel, CSV, Word, PDF и работа с базами данных)
  * **Двумерные массивы и матрицы**
  * **Консервация и расконсервация данных**
  * **Вывод данных во внешние программы и обработка структур «Матрица студентов»**
  * **И друге темы**


## Технологический стек и библиотеки

* **Язык программирования:** Python 3.x
* **Среда разработки (IDE):** PyCharm
* **Работа с данными:** `Pandas`, `openpyxl` (для .xlsx)
* **Форматы данных:** CSV, XLSX, DOCX, PDF, файлы баз данных (`.bd`)

4. В терминале установите необходимые библиотеки (если они ещё не установлены):
