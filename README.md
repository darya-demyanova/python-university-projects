# Комплекс лабораторных и практических работ по программированию на Python

Данный репозиторий содержит комплект лабораторных и практических работ, выполненных мной в рамках университетского курса по программированию на Python в МТУСИ.

Проект представляет собой единую модульную систему, объединенную главный интерактивным меню (`runProject.py`), которое позволяет выполнять предварительные расчеты, манипулировать данными и запускать любые лабораторные работы прямо из консоли.

---

## Подробный обзор модулей и практических заданий

Все практические и лабораторные работы расположены внутри пакета `packageForPracticeTasks`:

* **`PracticalTask1/` — Основы работы со списками (Лабораторная работа №1)**
  * Базовые операции со списками, срезы, фильтрация и обработка числовых последовательностей.
* **`PracticalTask2/` — Методы обработки списков и модули (Лабораторная работа №2)**
  * Алгоритмы фильтрации, генерация списков, вычисление статистических показателей и организация кода в отдельные вспомогательные модули (`moduls.py`).
* **`PracticalTask2_1/` — Экспорт данных и работа с Pandas (Лабораторная работа №3)**
  * Интеграция Python со сторонними форматами, создание и обработка структурированных таблиц с использованием библиотеки `Pandas`.
* **`PracticalTask2_2/` — Мультиформатная обработка данных (Лабораторная работа №4)**
  * Комплексная работа с различными типами файлов: чтение, запись и конвертация данных между Excel (`.xlsx`), CSV (`.csv`), Word (`.docx`), PDF (`.pdf`) и локальными базами данных (`.bd` / `.db`).
* **`PracticalTask2_3/` — Двумерные массивы и матрицы (Лабораторная работа №5)**
  * Алгоритмы обработки матриц, транспонирование, поиск экстремумов и обработка таблиц распределения данных (например, датасетов с показателями по странам).
* **`PracticalTask2_5/` — Сериализация и хранение данных (Лабораторная работа №6)**
  * Техники «консервации» и «расконсервации» структур данных Python через модули `pickle`, `json` и объектное хранилище `shelve`.
* **`PracticalTask2_6/` — Бинарный вывод и матрица студентов (Лабораторная работа №7)**
  * Сохранение и загрузка бинарных матриц, вычисление результатов успеваемости студентов и формирование итоговых отчетов в форматах TXT, XLSX и SHELVE.
* **`PracticalTask2_7/` — Последовательная обработка и базы данных (Лабораторная работа №8)**
  * Анализ временных последовательностей, интеграция с файлами баз данных SQLite (`Vlog_posled.db`) и формирование структурированных Word-отчетов (`Vlog_Posled.docx`).
* **`PracticalTask2_8/` — Вспомогательные задачи обработки**
  * Дополнительные скрипты для генерации выборок и форматирования результатов.
* **`PracticalTask2_11/` & `PracticalTask2_12/` — Автоматизация отчетности и XLSX-тесты**
  * Формирование проверочных таблиц результатов (`test_results.xlsx`) и автоматизированная сборка отчетов.
* **`PracticalTask3/` — Алгоритмические задачи и функции**
  * Реализация пользовательских функций обработки данных и вычислений.
* **`PracticalTask4/` — Система учета данных (База данных и документы)**
  * Моделирование системы учета информации с использованием таблиц, текстовых дампов (`sis_table.txt`), документов `.docx` и базы данных `Sis_data.db`.
* **`PracticalTask5/` — Геометрические и инженерные расчеты**
  * Вычисление площадей, параметров прямоугольных фигур и генерация связанных отчетов в форматах Word (`Ploshad_pram.docx`) и Excel (`Ploshad_pram.xlsx`).
* **`PracticalTask6/` — Численные методы (Метод Итераций Ньютона)**
  * Реализация численного метода Ньютона для нахождения корней уравнений, сохранение итераций в `.txt` и генерация расчетных книг Excel с поддержкой макросов (`newton_itertions.xlsm`).

## Технологический стек и библиотеки

* **Язык программирования:** Python 3.13
* **Обработка и анализ данных:** `Pandas`, `openpyxl` (работа с файлами `.xlsx` / `.xlsm`)
* **Форматы данных:** CSV, XLSX, XLSM, DOCX, PDF, BIN, SHELVE, DB / BD
* **Среда разработки (IDE):** PyCharm
